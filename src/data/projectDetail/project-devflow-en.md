# An app that brought together many technologies, built as part of an intensive NextJS learning course

## The app included many features — some visible on screen, others running behind the scenes

| Technology | Purpose |
| ---------- | ------- |
| NextJS | Framework for page navigation, API definition, and server-side operations |
| MongoDB (mongoose) | Database — flexible to use and fast in response |
| Tailwindcss | Easy UI styling and component-focused development |
| MDX | Displaying and syntax-highlighting code, allowing markdown authoring from the site |

> The above were only the major technologies — the app includes many supporting libraries

## Features learned and implemented during development

- Managing multiple accounts and signing in via third-party services like Google and GitHub (**OAuth**)
- Adding questions and answering them, with the ability to support AI-powered answers
- An internal error handling system to ensure the app doesn't crash
- A logging system for tracking app state, database connections, and errors
- Job search functionality, including handling countries and available positions
- Multiple search techniques — local to a single page or site-wide search

> You can try the site to experience it yourself
