## Building the map was the biggest challenge — my team designed it, but I converted it into code

Challenges I faced:

- Building points from filters and placing them in the correct position
- Dividing the map into multiple sections
- Ensuring no more than one map records at the same moment
- Completing the journey correctly and preventing user and journey conflicts
- Building four maps for each type of pilgrimage ritual + Umrah
- Building a reusable and easily maintainable base
